How I work

Four rules, each with a number behind it

Every rule links to the line of a README that proves it was followed.

Measure, don’t claim

Every product is scored against the naive thing people actually do, and the number is on the page.

HomeCast the sector-median rule agents use scores 26.6% MAPE

Break it on purpose

Each headline claim has a test that goes red when the mechanism behind it is removed.

Red Light, Green Light 6 of 6 mutations caught by tests that already existed

Publish the bad number

A fix that did not help stays in the report, next to the ones that did.

Nightingale recalibration did not demonstrably help one hospital, and the report says so

It runs on your device

No server anywhere. The model you read about is the model that runs, and nothing you load leaves the tab.

About

The person behind the products

Building now October 2026 · finishing Wavelength, a music recommender that runs in your browser.

I'm a computer science graduate from Hyderabad. I work as an AI engineer at Navatej Technologies, remotely, and I spend the rest of my time building the products on this page: machine learning, computer vision and full applications, each one published with the numbers behind it.

I come from a family of doctors in Kurnool. My parents run a small nursing home and my younger brother is studying medicine. I'm the one who went into computers, and a lot of what I want to build is for people like my parents' patients: tools that just work, on whatever device they have.

I like finishing things properly. If I start something, I learn it, plan it and take it all the way, and I would rather publish the bad number than hide it.
