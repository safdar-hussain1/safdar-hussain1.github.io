Open Nightingale

It did not start inside this page. It runs on its own tab.

In short

Six disease-risk models that show their uncertainty, running in the page.

Runs on your device

Measured

  • six clinical conditions in one calibrated pipeline
  • heart disease ROC-AUC 0.8892, interval 0.8663 to 0.9101
  • the browser and Python agree to 7.22e-16 in the worst case
  • recalibration did not demonstrably help one hospital, and the report says so

Every figure is quoted from the README each line links to.

What it does not do

Screening-triage models on small public datasets, not diagnostic devices; only heart disease has external validation.

Built with

Python · scikit-learn · XGBoost · JavaScript · pytest
