Open WardOS

In short

A 32-bed hospital running on a real database in your browser.

Runs on your device

Measured

  • 364 tests, no server, every byte stays on your device
  • 32 beds in four colour-coded wards
  • 0 of 87 invoices wrong in the six-month benchmark
  • 0 double bookings across 104 admissions

Each line links to the README it is quoted from.

What it does not do

One hospital on one device with a frozen demo clock; the browser database can be evicted, and a reset restores the seeded hospital.

Built with

TypeScript · React · SQLite as WebAssembly · Vite · Vitest
