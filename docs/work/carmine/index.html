Carmine

Virtual makeup that keeps your skin's texture, live on your camera.

Carmine, running in this page Open in its own tab
Open Carmine

It did not start inside this page. It runs on its own tab.

How it was measured

  • lip texture correlation 0.988, the highest of the five methods benchmarked
  • benchmarked on 26 photographs
  • 26.6 ms a frame, about 37.6 fps, live on an M1 Pro
  • 259 pytest tests
  • 118 vitest tests

Every figure is quoted from the README each line links to.

What it does not do

Benchmarked on 26 private portraits whose numbers are public and whose photos are not; the landmarker, not the renderer, is the main source of disagreement between the two surfaces.

Built with

Python, OpenCV, MediaPipe, TypeScript, WebGL2, Vite

Where it runs

On your own device. It uses your camera.
